# INFINITY WAVE MUSIC

Official website: **SOUND WITHOUT LIMITS.** React + Vite + React Router (HashRouter), hosted free on GitHub Pages.

Live: https://motlogelwaisiah-collab.github.io/infinity-wave-music/

## Run locally
    npm install
    npm run dev       # development
    npm run build     # production build into dist/

## Update the website
- Content (releases, videos, news, social links): edit `src/data/site.js`.
- Pages: `src/pages/Pages.jsx`. Navigation/footer: `src/components/Shell.jsx`. Styling: `src/index.css`.
- Images: `src/assets/`.
- Commit and push to `main`. GitHub Actions builds and deploys automatically (or run it manually from the Actions tab).
